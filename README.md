# SejmSim 2027

**41-district probabilistic Sejm projection engine.** Translates national polling
scenarios for Polish parliamentary elections into probabilistic 460-seat Sejm
allocations using a disaggregated D'Hondt simulation engine with a
10,000-iteration Monte Carlo sampler — computed entirely client-side in a Web
Worker (~300 ms on a modern laptop; the UI thread never blocks).

## Stack

- Vite + React 19 + TypeScript (static export, zero server dependency)
- Tailwind CSS v4 + shadcn-style Radix primitives
- D3-style custom SVG hemicycle (460 dots, 231 / 276 majority markers)
- Custom SVG vector map of Poland's 41 electoral districts
- Recharts for Monte Carlo seat distributions and threshold-mortality charts
- URL-driven state — every scenario is shareable via the query string

## Model (6 stages)

1. **Logit-normal sampler** — national vectors drawn as
   `Z ~ N(μ, Σ)` in log-ratio space (residual "others" as reference), softmax back
   to a simplex. Σ = independent σ + equicorrelated common shock (ρ = 0.25).
2. **Prior construction** — `g_{k,d} = (w25·s²⁵ + w23·s²³ + ε) / mix_nat`,
   a geographic multiplier (~1.0 mean) blended from the 2023 Sejm and 2025
   presidential (R1) district matrices.
3. **Disaggregation** — `L_{k,d} = C_k · g_{k,d}^{α_k}`, normalized per district.
4. **National gatekeeper** — 5% single party / 8% coalition; discarded votes are
   eliminated locally.
5. **District D'Hondt** — quotients `V/m` for m = 1..M_d in each of the 41
   districts (M_d = 7–20).
6. **Diagnostics** — exact vote-flip requirement
   `ΔV_{k,d} = (S_{k,d}+1)·q* − V_{k,d}` plus a full quotient audit table.

Candidate→committee prior mapping: Trzaskowski→KO, Nawrocki+Jakubiak→PiS,
Mentzen→Konfederacja, Braun→KKP, Zandberg→Razem, Biejat→Lewica,
Hołownia→PSL/P2050. R+ uses a flat prior (α = 0 default).

## Data

`src/data/districts.json` — generated by `scripts/build_data.py` from **official
PKW sources**:

- Sejm 2023: `okregi_sejm_csv.zip`, `wyniki_gl_na_listy_po_okregach_sejm_csv.zip`,
  `protokoly_po_obwodach_sejm_csv.zip` (sejmsenat2023.pkw.gov.pl)
- 2025 presidential R1: per-precinct protocols (PKW export mirrored at
  hrpunio/PLWybory), re-aggregated into sejm districts via a TERYT gmina→okręg
  bridge (2,496 gminas). Abroad/ship precincts are excluded — they belong to no
  sejm district.

To regenerate: `python scripts/build_data.py` (downloads into `scripts/raw/`,
gitignored).

`src/data/map.json` — district boundary paths extracted from
`scripts/SejmMap_source.tsx`, MIT-licensed © 2023 Dyzio
(github.com/Dyzio18/2023wybory.pl). Used with attribution.

## Develop / build / deploy

```bash
npm install
npm run dev       # dev server
npm run build     # typecheck + static build to dist/
npm run preview   # serve dist at /SejmSim/
node scripts/test_engine.mjs   # headless worker sanity check (after build)
```

Deployment: `.github/workflows/deploy.yml` builds on every push to `main` and
publishes `dist/` via GitHub Pages (`VITE_BASE` is set to `/<repo>/` so forks
work out of the box). Enable **Settings → Pages → Source: GitHub Actions**.
